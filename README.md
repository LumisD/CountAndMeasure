Application "Measure and Count".
It helps to measure and count chipboards, wood, etc.
The work consists of two parts: making a list of sizes and then checking the received parts.

First: create a list of chipboards with sizes.
If a chipboard has a grain direction, it's possible to mark a specific size that must have that direction.
If there are chipboards with different colors, it's possible to set color for each detail.

Second: after receiving chipboards, start to measure and count them.
Start by entering the measured size, and the app will show the closest size that you can pick.
If a size, direction, or color is not correct, you can mark it and provide a note.

Once you have finished measuring, if something is wrong, you will have a list of issues 
that you can send to the person who cut/made these items for you

All these features greatly accelerate the measuring and counting process for a large number of chipboards.
